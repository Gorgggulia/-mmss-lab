# Система контролю якості на виробничій лінії

Навчальний проєкт з дисципліни «Архітектури мультимедійних та смартсистем»
(КПІ ім. Ігоря Сікорського, ФПМ, кафедра ПЗКС). Лабораторна робота 1:
аналіз предметної області та архітектурний опис за ISO/IEC/IEEE 42010:2022.

## Про систему

Кіберфізична система, яка в реальному часі аналізує вироби на конвеєрі за
допомогою комп'ютерного зору, вібраційних сенсорів обладнання та даних про
швидкість лінії, виявляє дефекти й аномалії, сповіщає оператора та
технолога з якості, веде журнал подій для простежуваності партій і
підтримує прогнозне обслуговування обладнання. Детальний опис — у
[`docs/requirements.md`](docs/requirements.md).

## Як переглянути діаграми

Кожне архітектурне подання є у двох форматах:

- **`.svg`** — вже згенероване зображення, відкривається в будь-якому
  браузері без додаткових інструментів.
- **`.mmd`** — вихідний код Mermaid; для редагування зручно відкрити
  у VS Code з розширенням `bierner.markdown-mermaid`, або вставити вміст
  на [mermaid.live](https://mermaid.live) для перегляду й повторного
  експорту в SVG.
